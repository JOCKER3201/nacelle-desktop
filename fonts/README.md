# fonts/

Wrzuć tutaj pliki .ttf/.otf, aby uzyskać wygląd 1:1 z eDEX-UI:

- `united_sans_medium.ttf` — font UI (nagłówki, zegar, klawiatura),
- `fira_mono.ttf` — font terminala.

Konwersja z repozytorium eDEX-UI (pliki .woff2): patrz README w katalogu głównym
(`woff2_decompress`). Bez tych plików ng-term użyje najbliższych fontów systemowych.
